## TikTok App Review Setup

In the **existing TikTok app’s production Basic Info**:

1. Upload `assets/app-icon.png` unchanged as the app icon.
2. Set Website URL to `https://mahmoudblog4-png.github.io/quran-reels-publisher-site/` (including the trailing slash).
3. Set Privacy Policy URL to `https://mahmoudblog4-png.github.io/quran-reels-publisher-site/privacy.html`.
4. Set Terms of Service URL to `https://mahmoudblog4-png.github.io/quran-reels-publisher-site/terms.html`.
5. Preserve the existing verification, OAuth settings, and scopes. Save the changes.
6. Compare the saved app preview with the live site logo and favicon. Resubmit only after the live verification is complete.

The publishing orchestrator has no authenticated TikTok interface. These steps are manual; no portal changes or approval outcome are claimed. This update addresses the submitted icon and website URL consistency only; TikTok review decisions remain with TikTok.
